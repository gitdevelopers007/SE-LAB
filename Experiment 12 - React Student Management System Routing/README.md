# Experiment 12 - React Student Management System with Routing

## Objective
Create a **React single-page application (SPA)** for a Student Management System with:
1. **Registration Page** - Enrolling new student records into state.
2. **Login Page** - User sign-in and session profile.
3. **Contact Page** - Inquiry form for academic matters.
4. **About Page** - Overview of SPA and institutional information.
5. **Students Page** - Listing registered students with delete capability.
6. **Routing** - Seamless navigation without page refresh.

---

## How to Run in VS Code

### Option 1: Run with Node.js Server
```bash
cd "Experiment 12 - React Student Management System Routing"
node server.js
```
Open your browser at:
```
http://localhost:3012
```

### Option 2: Live Server / Direct Browser
- Right-click `index.html` in VS Code and select **Open with Live Server**.
- Or double-click `index.html` to open directly in Chrome/Edge/Firefox.
